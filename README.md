# Chat Dimension: Robot Raiders

A first-person 3D island adventure built with React, Vite and Three.js.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

GitHub Pages builds the Vite app and publishes the `dist` folder whenever changes are pushed to `main`.

## Controls
- WASD / arrow keys: move
- Mouse: look around (click the game to lock the pointer)
- Space: jump
- Click or F: fire pulse
- Touch: on-screen movement, turn, jump and pulse buttons; drag the game view to look around
